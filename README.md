# Kotlin Learning Project 🚀

This repository journy in learning the **Kotlin programming language**.

## 📚 Purpose

The goal of this project is to:

- Understand Kotlin syntax and core concepts
- Practice problem-solving using Kotlin
- Build a strong foundation for Android and backend development
- Experiment with small programs and logic implementations

## 🛠️ Topics Covered

This project includes practice with:

- Variables and data types
- Null safety (`?`, `?:`, `!!`)
- Control flow (`if`, `when`, loops)
- Functions and return types
- Collections (Lists, Arrays)
- Basic input/output
- Simple algorithms (e.g., even/odd checker)
